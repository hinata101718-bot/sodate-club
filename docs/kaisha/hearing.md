# ヒアリング記録（会社経営ゲーム）

書き方：問番号・決まったこと・おすすめどおりか・ヒナタさんの言葉

- 問1・業種はまだ決めず、ほかの質問に答えながら一緒に決める・おすすめなし・「まだ決めていない」
- 問2・いちばん味わいたいのは「会社が大きくなる」（小さな会社が売上・社員数・拠点を増やして大企業になる）・おすすめどおり・「会社が大きくなる」
- 問3・プレイヤーの立場は社長（何を作るか、誰を雇うか、いくら使うかを自分で決める）・おすすめどおり・「社長（おすすめ）」
- 問4・手本はドット絵の箱庭経営（小さな会社の中で社員が動き回り、眺めながら育てる手軽な遊び方）。名前や絵はまねせずオリジナルで作る・おすすめどおり・「ドット絵の箱庭経営」
- 問5・業種は1つにしぼって作りこむ（どの業種かは次の問で決める）・おすすめどおり・「1つにしぼる（おすすめ）」
- 問6・会社が大きくなったことは、せまい事務所から部屋が広がり、最後は自社ビルになる形で見せる（箱庭の中の社員の数と建物の変化）・おすすめどおり・「事務所→ビルになる（おすすめ）」
- 問7・主にiPhoneのSafariで、縦持ち・指で操作する・おすすめどおり・「iPhoneのSafari（おすすめ）」
- 問8・遊ぶのは寝る前（1回15〜30分）と休みの日（1時間以上）。移動中の短い遊び方は考えなくてよい・おすすめ（移動中・寝る前）の一部＋休みの日・「寝る前に15〜30分（おすすめ）, 休みの日に1時間以上」
- 問9・業種はゲーム会社（社員でチームを組んでゲームを作り、発売して売れ行きや評価が出る）・おすすめどおり・「ゲーム会社（おすすめ）」
- 問10・時間は開いているあいだ勝手に流れ、一時停止・ふつう・速いを切りかえられる・おすすめどおり・「勝手に流れて速さを変えられる（おすすめ）」
- 問11・ゲームに終わりはなく、「社員○人」「自社ビル」などの節目の目標が順番に出てくる・おすすめどおり・「終わりなし＋節目の目標（おすすめ）」
- 問12・ゲームを作るときに社長が決めるのは、担当する社員、出す機種・規模（小さく作るか大作か）、開発中の方針（「絵に力を入れる」「早く仕上げる」など）。ジャンルとテーマは選ばなかった（次の問で確かめる）・おすすめ（ジャンルとテーマ・担当する社員）の一部＋機種・規模、開発中の方針・「担当する社員（おすすめ）, 出す機種・規模, 開発中の方針」
- 問13・社員の職種は、作る4職種（プランナー・プログラマー・デザイナー・サウンド）に加えて、会社を動かす人（営業・広報・人事など）も雇う・おすすめ（4職種）とはちがう・「4つ＋会社を支える人」
- 問14・架空のゲーム機が時代とともに出て、大きくなったら自社のゲーム機も作って発売できる（実在の機種名・会社名は使わない）・おすすめ（架空の機種が出る）＋自社のゲーム機・「いつか自社でゲーム機も作れる」
- 問15・発売のあとは、レビューの点数が1人ずつ開くドキドキと、売れ行きが伸びていく様子の両方で盛り上げる・おすすめ（レビューの点数）＋売れ行き・「両方」
- 問16・作るゲームの中身（「RPG×宇宙」のようなジャンルとテーマ）は、プランナーがいくつか企画を持ってきて、社長が1つ選ぶ。腕のいいプランナーほどいい企画が出る・おすすめどおり・「プランナーの企画から選ぶ（おすすめ）」
- 問17・会社を支える職種は広報（発売前の期待度・初週の売れ行き）、営業（売れ行きが長く続く・受託の仕事を取る）、人事（いい応募者を集める・やる気や辞めにくさ）。経理は入れない・おすすめ（広報・営業）＋人事・「広報（おすすめ）, 営業（おすすめ）, 人事」
- 問18・開発中の方針は、開発の節目ごとに2〜3回「絵に力を入れる？音楽に力を入れる？」のような分かれ道が出て選ぶ。放っておいても進む・おすすめどおり・「途中で2〜3回、選ぶ場面が来る（おすすめ）」
- 問19・社員の能力は4〜5項目で、全員が同じ項目を持ち、職種によって生きる能力が変わる・おすすめ（職種の腕前1つ＋共通2つ）とはちがう・「4〜5項目」
- 問20・能力は企画・デザイン・プログラミング・サウンド・営業・採用・広報の7項目（職種ごとに1つ。問19の「4〜5項目」とくいちがうので次の問で確かめる）・おすすめ（企画・技術・絵・音・話術の5項目）とはちがう・「企画、デザイン、プログラミング、サウンド、営業、採用、広報」
- 問21・社員は、募集を出して応募者から選ぶ形と、毎年春に新卒が来る形で雇う（引き抜き・売り込みはなし）・おすすめどおり・「募集を出して応募者から選ぶ（おすすめ）, 毎年春に新卒が来る（おすすめ）」
- 問22・社員は、ゲームを作ると経験がたまって伸び、経験を積むと上の職種に変われ、たまにひらめき・覚醒で大きく伸びる（研修はなし）・おすすめ（経験・研修）の一部＋上の職種・覚醒・「ゲームを作ると経験がたまる（おすすめ）, 職種を変えて上の職種へ, ひらめき・覚醒」
- 問23・お金が足りなくなると銀行から借りられ、それでも返せないと倒産して最初から・おすすめどおり・「借金できて、返せないと倒産（おすすめ）」
- 問24・能力は問20の7項目（企画・デザイン・プログラミング・サウンド・営業・採用・広報）を全員が持つ。これにあわせて問19の「4〜5項目」を「7項目」に改める・おすすめどおり・「7項目にする（おすすめ）」
- 問25・経験を積むと、職種とは別に会社の中の役職（主任→課長→部長→役員）が上がり、給料も上がる・おすすめ（各職種に上が1段＋ディレクター）とはちがう・「役職（主任→課長→部長→役員）」
- 問26・小さなひらめきは箱庭の社員の頭の上に電球が出て少し伸び、たまに起きる大きな覚醒だけ全画面の演出を出す・おすすめどおり・「小さなひらめきは頭の上に電球、覚醒は全画面（おすすめ）」
- 問27・社員は能力のほかに、体力（働くと減り休むと戻る）、やる気（低いと辞めることがある）、性格・個性（働き方に少し影響）、年齢（若いほど伸びやすく、いつか定年）を持つ・おすすめ（体力・やる気）＋性格・年齢・「体力（おすすめ）, やる気（おすすめ）, 性格・個性, 年齢」
- 問28・事務所の箱庭は斜め上から見下ろす（ひし形の部屋で、机の並びや社員が歩き回る様子が見える）・おすすめどおり・「斜め上から見下ろす（おすすめ）」
- 問29・社員のドット絵は髪型・髪色・服の色などを組み合わせて一人ひとり違う見た目にする・おすすめどおり・「一人ひとり違う見た目（おすすめ）」

- 問31・ゲームの売上のほかに、受託の仕事、続編・シリーズ、自社ゲーム機の売上、グッズ・アニメ化でもお金が入る・おすすめ（受託）＋続編・ゲーム機・グッズ・「受託の仕事（おすすめ）, 続編・シリーズ, ゲーム機の売上, グッズ・アニメ化」
