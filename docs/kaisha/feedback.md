# 遊んだ感想の記録（PRESS START）

書き方：日付・どこで・ヒナタさんの言葉・原因（どのファイルの、どの決め方か）・直し方・状態

## 最初の版

### 1. 2026-11-28　はじめ方（最初の社員を雇う画面）
- ヒナタさんの言葉：「日本語への違和感。1人を雇う／残りの2人を〜雇う／他に得意。雇う→採用とかの方がいいと思う。もっと日本語擦り合わせよう」
- 画面の文：「3人が応募してきた。1人を雇う。残りの2人も、6週のあいだは「社員」から雇える。ゲームの面白さは、プランナーとプログラマーがいると出やすい。」「ほかに得意：デザイン 14」「雇う」（ボタン）
- 原因：public/press-start/js/app.js の showFirstHire と candCard。言い切りの文を短く並べすぎて、説明書のような硬さになった。「雇う」がくり返される。「ほかに得意」は、14のような低い数字にも付けていた
- 直し方：問75〜問78で決め直した（社員を入れることは「採用」、説明と案内はです・ますで短く、本職以外の能力は30以上のときだけ「これも得意」）。docs/kaisha/nihongo.md を書き直し、画面の文をすべてこの決め方で直した。担当を選ぶ画面の「人が多いと早く進む」は仕組みとちがっていたので「人数が多いほど出来はよくなる」に直した
- 状態：直した（最初の版の2回目）

### 2. 2026-11-28　画面全体の日本語（問79〜問96）
- ヒナタさんの言葉：「いまの会社経営ゲームの日本語の違和感を消したい。どういう日本語がダメか細かくヒアリングしながら擦り合わせて」
- 原因：同じ言葉がひらがなと漢字でまざっていた（とじる／閉じる など）。お金の言葉が説明っぽかった（手持ちのお金・差し引き）。お知らせにです・ますがまざっていた。作る側の予定（「つぎの版で足します」）が画面に出ていた。社員のひとことがネタっぽく、敬語とタメ口がまざっていた。レビューは部品をはめこむ作りで「操作の気持ちよさが単調なのが惜しい」のような変な文ができ、松本の「でも、抜けた先は面白いです」は前の文とつながっていなかった
- 直し方：問79〜問96で決め直し、docs/kaisha/nihongo.md に書き足した。public/press-start/js の data.js（社員のひとこと・レビュー・方針・受託）、sim.js（お知らせ・企画のセリフ・レビューの組み立て）、app.js（画面の名前・ボタン・説明）を直した。レビューは「どんなゲームか＋良いところ＋惜しいところ」の3文にし、ジャンルと題材ごとに、そのまま文になる言い方を持たせた。前の版の保存にある「第1チーム」は、読み込むときに「開発1課」に直す
- 状態：直した（最初の版の3回目）
