# 企画書「PRESS START」

もとになる記録：docs/kaisha/hearing.md（問1〜問70）
見本の画面：docs/kaisha/mihon.html（3つ目の版）

★がついているところは、Claudeが決めたところです。ちがっていたら教えてください。直します。
★がついていないところは、ヒアリングでヒナタさんが決めたところです。

## 1. ひとことで言うと

1980年ごろ、自宅のガレージでゲーム会社を始め、社長として社員を雇ってゲームを作り、約200人の高層本社ビルの会社まで大きくしていくゲーム。
ドット絵の事務所を斜め上から眺めながら、一人ひとり見た目のちがう社員が働く様子を見守る。

- いちばん味わいたいのは「会社が大きくなる」こと（問2）
- プレイヤーは社長。何を作るか、誰を雇うか、いくら使うかを自分で決める（問3）
- 手本はドット絵の箱庭経営の遊び方（問4）。ジャンルが同じ有名な作品はあるが、名前・キャラクター・見た目・細かい仕組みはまねせず、オリジナルで作る
- 業種はゲーム会社1つにしぼって作りこむ（問5・問9）
- 遊ぶのは寝る前（15〜30分）と休みの日（1時間以上）（問8）
- iPhoneのSafariで、縦持ち・指で操作（問7）。このリポジトリの中の別のアプリとして置き、ホーム画面に追加できる（問42）
  - 場所は「ゆめのおうち」と同じGitHub Pagesの `/press-start/`★
- アプリの名前は「PRESS START」（問50）

## 2. 時間と終わり

- 開いているあいだ、時間は勝手に流れる。一時停止・ふつう・速いを切りかえられる（問10）
- 「ふつう」でゲームの中の1年は約30分、「速い」はその半分（問34）
  - 時間の区切りは「週」。1年＝48週（1か月4週）★。ふつうで1週は約37秒★
  - 閉じているあいだは進まない★（問10で「閉じていても進む」は選ばなかったため）
- 1980年ごろの「ゲームのあけぼの時代」から始まる（問35）。始まりは1980年4月1週★
- 終わりはなく、節目の目標が順番に出てくる（問11・問37）
  - 会社の大きさ：社員○人、次の事務所へ引っ越し、自社ビル、業界○位
  - ヒットの記録：100万本突破、レビュー満点、ゲーム大賞
  - お金：売上○億円、借金完済
  - 新しいことを始める：初の続編、自社ゲーム機、初のアニメ化
  - 目標は画面上に1つずつ出し、達成すると次が出る★。ごほうびはお金と名声★
- お金が足りなくなると銀行から借りられる。返せないと倒産して最初から（問23）
  - 借りられる上限は会社の大きさで決まる★。返済の期限を過ぎて返せないと倒産★
- 自動でiPhoneの中に保存する。念のためファイルに書き出して備えられる（問38）

## 3. はじめ方

- 始めるときに、社名と社長の名前を自分で入れる（問48）
- 最初は自宅のガレージで、社長＋社員1人★。手持ちのお金は300万円★
- 最初の社員は、募集で来た2〜3人から選ぶ★（はじめての募集の練習をかねる）

## 4. 画面

見本の画面（docs/kaisha/mihon.html）のとおり。

- 色合いは、すっきりした青と白（明るい水色と白に緑の差し色）（問65）
- ドット絵は昔のゲームのような、色数の少ないもの（問49）
- ドット風の文字は見出しと数字（お金・点数など）だけ。説明やひとことはふつうの文字（問64）
- 音は効果音だけ（レビューの点数が開く音、覚醒の音など。ピコピコした昔のゲーム風）。設定で消せる（問51）

### メイン画面（問57・問58・問60・問67）
- 箱庭が画面の大半
- 上の帯
  - 社名・社長の名前・「記録」（未読の数）・「設定」★
  - 日付とお金
  - 速さの切りかえと、開発中のゲーム（チーム名・作品名・進み具合のバー）。チームが複数なら横にすべらせて切りかえる
- 下のメニューは「開発・社員・組織・経営・業界」の5つ。ドットの絵つき★
- 細かいお知らせは、箱庭の上に吹き出しで短く流れて消える。見逃しても「記録」であとから読める
- 開発の進み具合は、上の帯と箱庭の中の両方で見せる（問60）
  - 箱庭の中：社員の頭の上から「面白さ+2」などが飛び出し、壁のホワイトボードに進み具合が出る

### メニューの開き方（問59）
- 下からせり上がり、上に箱庭が少し見えたまま時間も流れ続ける。下に引っぱると閉じる

### 時間が止まる場面（問66）
- 開発の分かれ道や大事なお知らせが来たら、時間が一時停止して、画面の真ん中に選ぶ画面が出る。選んだらまた流れる

## 5. 箱庭（事務所）

- 斜め上から見下ろす（ひし形の部屋で、机の並びや社員が歩き回る様子が見える）（問28）
- 社員のドット絵は、髪型・髪の色・肌の色・服の色を組み合わせて一人ひとり違う見た目（問29）
- 社員は細かく描き、表情や動きを出す（問70）
  - キーボードを打つ、歩く（コーヒーを取りに行くなど）、まばたき、ソファで寝る（体力が少ないとき）★
- 箱庭では、社員をタップして様子を見るだけ。家具や設備を置く遊びはない（問30）
  - 部屋の家具（机・本棚・ホワイトボード・植物・コーヒーメーカー・ソファなど）は、事務所の段階ごとに決まったものが置かれる★
- 事務所は7段階。お金を払って、引っ越すかどうかは自分で決める（問36・問40）

| 段階 | 場所 | 人数の上限 |
|---|---|---|
| ① | 自宅のガレージ | 〜2人★ |
| ② | アパートの一室 | 〜5人★ |
| ③ | 雑居ビルの小さな事務所 | 〜10人★ |
| ④ | ビルのワンフロア | 〜25人★ |
| ⑤ | ビルの2フロア | 〜50人★ |
| ⑥ | 自社ビル | 〜100人★ |
| ⑦ | 高層本社ビル | 階を増やして〜200人（問44） |

（人数は社長をのぞいた社員の数。問40の「もっと多く」と問44の「約200人」から決めた★）

- 広い事務所ほど家賃が高い（問40）
- 1つの階に20〜30人。人数が多くなったら階を切りかえて眺める（問44）

## 6. 社員

### 職種（問13・問17）
- 作る4職種：プランナー（企画）・プログラマー・デザイナー（絵）・サウンド
- 会社を支える3職種：
  - 広報：発売前の期待度と初週の売れ行きを上げる
  - 営業：売れ行きを長く続かせ、受託の仕事を取ってくる
  - 人事：いい応募者を集め、社員のやる気と辞めにくさに効く
- 経理はない

### 能力（問19・問20・問24）
- 全員が7項目を持つ：企画・デザイン・プログラミング・サウンド・営業・採用・広報
- 職種によって生きる能力が変わる。「この人は実は絵もうまい」といった発見がある
- 数字は1〜100★。70以上は金色★
  - プランナー＝企画、プログラマー＝プログラミング、デザイナー＝デザイン、サウンド＝サウンド、広報＝広報、営業＝営業、人事＝採用★

### そのほかの状態（問27）
- 体力：働くと減り、休むと戻る。少ないと仕事が遅くなり、ソファで寝る★
- やる気：ヒット・給料・ボーナスで上がる。低いままだと辞めることがある
- 性格・個性：「夜型」「のんびり屋」など1つ。働き方に少し影響する
  - 性格の種類は6〜8個★
- 年齢：若いほど伸びやすい。いつか定年で辞める
  - 定年は60歳★

### 雇い方（問21）
- お金をかけて募集を出すと、数人の応募者が来る。能力と給料を見て雇う。人事がいるといい人が来る
- 毎年春の入社式で新卒が入る。能力は低いが給料が安く、伸びしろがある（問33）

### 伸び方（問22・問25・問26）
- ゲームを作ると、使った能力に経験がたまって伸びる。大作やヒット作ほど大きく伸びる
- 経験を積むと役職が上がり、給料も上がる：社員→主任→課長→部長→役員
- 小さなひらめき：箱庭の社員の頭の上に電球が出て、少し伸びる
- 大きな覚醒：たまに起きて大きく伸び、全画面の「覚醒！！」を出す。台詞はない

### 社員カード（問63）
- 顔・名前・職種・役職・年齢・性格・ひとこと
- 7つの能力（数字と棒）、体力・やる気のゲージ
- 給料、次の役職までの経験★
- 「異動」「職種を変える」ボタン

## 7. 組織と組織図（問45・問53〜問55・問62）

- 社長の下に開発部・営業部・広報部・人事部がある。開発部の中に第1チーム・第2チーム…がある
- 部長が部を、課長がチームをまとめる
- 開発チームがいくつもできたら、課長・部長をチームのリーダーにして、担当の割り振りや分かれ道を任せられる。任せずに自分で決めてもよい
- 組織図は最初から使える。ガレージの2人のころの「社長―社員」の小さな図から枝分かれしていく
  - 部やチームができるのは、社員が増えてから★（第2チームは社員8人から★。作ってみて、10人だと③の事務所が満員になるまで増やせないため8人にした）
- 見た目：いちばん上に社長、部→チーム→社員へ下に枝分かれ。社員はドットの顔で並ぶ
- ふだんは眺めて会社の形を楽しむ。顔をタップすると異動、点線の枠からリーダーを任命できる。指で動かして見たり、部をたたんだりできる

## 8. ゲームを作る

### 流れ
1. 「開発」を押すと、プランナーが企画をいくつか持ってくる（問16）
   - 企画は3つ★。中身は「ジャンル×テーマ」
   - それぞれにプランナーの見立て（◎○△）がつく。腕がいいほど見立てが当たる★
2. 規模（小品・ふつう・大作）と機種を選ぶ（問12）
   - 例：小品 3か月・80万円、ふつう 6か月・200万円、大作 12か月・600万円★
3. 担当する社員を決める（問12）
4. 開発が始まる。社員が働くと「面白さ」「絵」「音」がたまっていく★
5. 開発の節目ごとに、2〜3回の分かれ道で方針を選ぶ（問18）
   - 例：「絵に力を入れる？」「音楽に力を入れる？」「早く仕上げる？」
   - 放っておいても進む（問18）が、選ぶ画面が出ているあいだは時間が止まる（問66）
6. 発売

- ジャンルは10個（格闘は1986年、音楽は1988年から）、テーマは14個★
- ジャンルとテーマの組み合わせには相性がある★。流行りは時代とともに変わる★

### 発売（問15・問41・問61）
- 画面が切りかわり、評論家4人のドット絵が並ぶ
- タップするごとに1人ずつ、感想→10点満点の点数の順に開く。最後に合計（40点満点）
- 発売前の期待度と予約本数も出す★（広報の働き）
- 点数が出そろったら、売れ行きの画面へ。本数が週ごとに増え、ランキングを上がっていく様子を見る（問15）

### ゲーム機（問14）
- 架空のゲーム機が、年が進むとともに発売され、古い機種はすたれる（実在の機種名・会社名は使わない）
- 機種ごとに普及台数があり、多い機種ほど売れやすい★。出すのに開発費がかかる★
- 大きくなったら、自社のゲーム機も作って発売できる

## 9. お金

- 入るお金（問31）：ゲームの売上、受託の仕事、続編・シリーズ、自社ゲーム機の売上、グッズ・アニメ化
- 出るお金★：給料（毎月）、家賃（毎月）、開発費、募集の費用、広告、引っ越し、借金の返済
- 「経営」の画面で、お金の流れ・借金・引っ越しを見る（問58）

## 10. 業界

- 架空のライバル会社がいくつかあり、ゲームを出してくる（問32）
  - ライバルは5社★
- 業界の順位と毎週の売上ランキングで、自分の位置がわかる。直接の奪い合いや引き抜きはない
- 毎年の出来事（問33）
  - 春：入社式（新卒が入る）
  - 夏：ゲーム展示会（お金を払って出展すると、開発中の作品の期待度が上がる）
  - 年末：ゲーム大賞の発表、決算とボーナス（ボーナスを払うとやる気が上がる）
- 「業界」の画面で、ランキングとゲーム機を見る（問58）

## 11. 最初の版に入れるもの・あとで足すもの（問39）

最初の版は芯だけ。触ってみて楽しいか確かめてから、残りを足す。

### 最初の版に入れる
- 社名・社長の名前を入れて始める
- 箱庭（社員が動く）、時間の流れと速さの切りかえ、時間が止まる場面
- 社員：7職種・7能力・体力・やる気・性格・年齢、募集で雇う、春の新卒
- ゲームを作る：企画3つから選ぶ、規模、機種、担当、分かれ道、レビュー発表、売れ行き
- 伸び方：経験、役職、ひらめき（電球）、覚醒（全画面）
- 組織図（部・チーム・リーダーの任命・異動）（問55）
- お金：給料・家賃・開発費、借金と倒産、受託の仕事
- 引っ越し：③雑居ビルの事務所まで★
- 架空のゲーム機（3〜4機種★）、ライバル会社と売上ランキング
- 年末のゲーム大賞、決算・ボーナス、春の入社式
- 節目の目標、記録、自動保存とファイルへの書き出し、効果音

### あとで足す
- 自社ゲーム機、グッズ・アニメ化、続編・シリーズ（問39）
- 夏のゲーム展示会（問39）
- ④以降の事務所、階の切りかえ、約200人の会社★
- チームが3つ以上のとき、リーダーに任せる細かい設定★

## 12. 作る順番★

1. 箱庭（部屋・社員の動き）と時間の流れ
2. 社員と募集、社員カード
3. ゲームを作る流れ（企画→規模・機種→担当→分かれ道→レビュー→売れ行き）
4. お金・借金・倒産、受託の仕事
5. 組織図、ライバルとランキング、年の出来事
6. 引っ越し、節目の目標、記録、保存、効果音
7. 数字の釣り合いを確かめる（何年か回して、早すぎず遅すぎず大きくなるか）
