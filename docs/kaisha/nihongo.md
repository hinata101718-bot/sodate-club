# PRESS START の日本語

もとになる記録：docs/kaisha/hearing.md（問71〜問96）
ゲームの中の文は、すべてこの決まりで書く。書いたら、下の「ダメな例」に当てはまらないか見直す。

## 1. 場所ごとの書き方

### お知らせ（吹き出し・記録）（問71）
新聞の見出しのように、起きたことだけを短く書く。

- よい：「佐藤がひらめいた。デザインが上がった」「ハガネ商会が新作を出した」「高橋が疲れている」
- よい：「『コスモクエスト』が10万本を超えた！」（大きいことだけ「！」）
- よい：「借金を期限までに返せなかった」「資金が底をついた。来月払えなければ倒産する」（悪い知らせも「〜した」の形。問81）
- ダメ：「借金を期限までに返せませんでした。」（お知らせにです・ます）
- ダメ：「佐藤さんがひらめきました！デザインがアップしました！」（いちいち「！」、カタカナ語）
- ダメ：「ついにハガネ商会が待望の新作をリリース！」（盛り上げ、リリース）

### 社員のひとこと（問72・問87・問89）
職場で本当に言いそうな、地味な独り言。性格で少し変わる。
独り言はタメ口、人に話しかけるときはです・ます。同じ人の中でまぜない。

- よい：「この色、もうちょっといける気がする」「夜のほうがはかどるんですよね」「お昼、何にしようかな」「眠い……」
- ダメ：「今日もがんばります！」「最高のゲームを作りましょう！」（前向きすぎる決まり文句）
- ダメ：「フフフ、今夜も筆が踊るぜ」（キャラの作りすぎ）
- よい（独り言）：「この色、もう少し調整したい」「やっと動いた」「目が疲れた」
- よい（話しかけ）：「お茶、淹れてきますね」「何か手伝えることありますか」
- ダメ：「動いた。なんで動いたかはわからない」「バグがひとつ消えて、ふたつ出た」（よくあるネタ）
- ダメ：「面白いって、なんだろう」「ピコピコ鳴らしてもいいですか」（作り物っぽい）

### 評論家の感想（問73・問88・問90）
ゲーム雑誌の評のように、3文で書く。「どんなゲームか」＋「良いところ」＋「惜しいところ（ただ、／でも、でつなぐ）」。
点がとても高いときは惜しいところの代わりにほめる一言、とても低いときは良いところの代わりに惜しいところと締めの一言。
評論家ごとに見るところと語尾を変える（星野・岩田：言い切り、松本：です・ます、大野：言い切りで「〜と思う」）。
同じ語尾を1つの評の中で2回使わない（「〜と思う。でも、〜と思う。」はダメ）。
部品をはめこむときは、はめた結果がそのまま文として読めるかを、ジャンルと題材の全部で確かめる。

- よい：星野「宇宙の広さはよく出ている。戦いが単調なのが惜しい」
- よい：岩田「曲がいい。それだけで最後まで遊べた」
- よい：松本「序盤が長い。でも、抜けた先は面白いです」
- よい：星野「宇宙を題材にしたRPGだ。戦闘のテンポがいい。ただ、中盤から同じことのくり返しになる。」
- よい：松本「今回は野球のレースゲームです。操作にすぐなじめます。ただ、野球らしい駆け引きが足りないのが残念でした。」
- ダメ：「壮大な宇宙を舞台にした世界観が魅力的です。さらに楽しめると感じました。」（中身がない、整いすぎ）
- ダメ：「操作の気持ちよさが単調なのが惜しい。」（はめこんだ言葉と合っていない）
- ダメ：「遊びの芯がしっかりしている。」（かたい）
- ダメ：「絵もきれいです。でも、抜けた先は面白いです。」（前の文とつながっていない）

### 企画を持ってきたセリフ（問91）
社内の企画会議で言うように、落ち着いたです・ますで、なぜそう思うかを一言そえる。

- よい：「アクションとお化けは相性がいいと思います」「今年はレースものが売れています」「ちょっと賭けです。当たるかは読めません」
- ダメ：「アクションは今、来てます」「当たれば大きい。かも……」（くだけすぎ）

### ボタン（問74・問75・問95・問96）
押すと何が起きるかを、短い言葉で書く。
やめるときは［キャンセル］、見終えたときは［閉じる］、演出のあとは［OK］。

- よい：［採用］［求人を出す（¥20万）］［引っ越す］［← 戻る］［受注する］［リーダーを選ぶ］［リーダーを外す］［方針をリーダーに任せる］
- ダメ：［採用しましょう］［雇う］
- ダメ：［やめる］（取り消しの意味で）［面接を終える］［受ける］［＋ リーダーを任命］

### 説明と案内（問76）
です・ますで、短く書く。前置きや「〜しましょう」は付けない。同じ言葉を続けて使わない。数字を添える。

- よい：「応募者は3人です。まず1人を採用してください。ほかの2人も、5月3週までは「社員」から採用できます。」
- よい：「広報がいると、発売前の期待度が上がります。」「お金が足りません。あと¥80万です。」
- ダメ：「3人が応募してきた。1人を雇う。残りの2人も、6週のあいだは「社員」から雇える。」（言い切りを並べて硬い、「雇う」のくり返し）
- ダメ：「広報を雇うと、期待度を上げることができます。」（回りくどい）

- ダメ：「◎○△は佐藤の見立てです。企画の腕がいいほど当たります。」（仕組みの説明口調。印の横に「佐藤の予想」とだけ出す。問84）
- ダメ：「この先の事務所は、つぎの版で足します」（作る側の話。「いまは、これより広い事務所はありません」。問83）

### 能力の見せ方（問77）
- 本職以外の能力は、30以上のときだけ「これも得意：企画 31」と出す。低い数字に「得意」と付けない

## 2. 使わない言い方

| 使わない | 代わりに |
|---|---|
| 〜することができます | 〜できる |
| 〜となっております／〜となります | 〜だ・〜です（または言い切る） |
| 〜しましょう！ | 書かない。ボタンの言葉で伝える |
| 雇う | 採用（ボタンは［採用］、お知らせは「〜が入社した」） |
| 募集を出す | 求人を出す |
| さまざまな・多彩な・魅力的な・壮大な・圧倒的な | 具体的に何かを書く |
| ワクワク・ドキドキ（気持ちを押し付ける言葉） | 書かない |
| 実現・提供・活用・最適化・向上 | ふつうの言葉にする（「〜を作る」「上がる」） |
| リリース・アップ・ゲット・スキル・ステータス・パラメータ | 発売・上がる・手に入れる・腕前・能力 |
| あなたは〜／あなたの会社 | 主語を書かない。社名で書く |
| 〜的な（印象的な、本格的な） | 具体的に書く |
| 待望の・ついに・いよいよ・堂々の | 書かない（本当に節目のときだけ「ついに」） |
| 絵文字 | 使わない（ひらめきの電球はドット絵で出す） |
| 手持ちのお金／毎月出ていくお金／出ていったお金／差し引き | 資金／毎月の支出／支出／利益（問80） |
| 分かれ道 | 方針（「開発の方針 1／3・序盤」。問93） |
| 第1チーム | 開発1課（問94）。数えるときも「チーム」ではなく「開発課」 |
| 作る職種 | 開発職 |
| 受託の仕事を受けた | 〜を受注した（問85・問96） |
| ごほうび | 報酬 |

## 3. 気をつけること

- 「！」は本当に大きいことだけ。1つの画面に2つ以上出さない
- 体言止め（「〜発売。」「〜達成。」）を続けない
- 同じ形の文を3つ並べない（「〜した。〜した。〜した。」）
- 説明しすぎない。わかることは書かない
- 呼び方は名字だけ（「佐藤」）。社員のひとことでは、社員どうしは「さん」をつける
- 数字はアラビア数字。お金は「¥320万」「¥4.2億」
- ひらがなと漢字は、ふつうの大人向けの文と同じにする。同じ言葉を画面によって書き分けない（閉じる・続ける・戻る・残り・次の・全部・読み込む・作り始める・始める・最初から。問79）
- 画面の名前・ボタンは、ヒアリングで決めた言葉に合わせる（開発・社員・組織・経営・業界、記録、設定、企画、規模、機種、担当、方針、レビュー、期待度、予約、覚醒）
