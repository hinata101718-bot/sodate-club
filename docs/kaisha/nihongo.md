# PRESS START の日本語

もとになる記録：docs/kaisha/hearing.md（問71〜問74）
ゲームの中の文は、すべてこの決まりで書く。書いたら、下の「ダメな例」に当てはまらないか見直す。

## 1. 場所ごとの書き方

### お知らせ（吹き出し・記録）（問71）
新聞の見出しのように、起きたことだけを短く書く。

- よい：「佐藤がひらめいた。デザインが上がった」「ハガネ商会が新作を出した」「高橋が疲れている」
- よい：「『コスモクエスト』が10万本を超えた！」（大きいことだけ「！」）
- ダメ：「佐藤さんがひらめきました！デザインがアップしました！」（いちいち「！」、カタカナ語）
- ダメ：「ついにハガネ商会が待望の新作をリリース！」（盛り上げ、リリース）

### 社員のひとこと（問72）
職場で本当に言いそうな、地味で少しおかしみのある独り言。性格で少し変わる。

- よい：「この色、もうちょっといける気がする」「夜のほうがはかどるんですよね」「お昼、何にしようかな」「眠い……」
- ダメ：「今日もがんばります！」「最高のゲームを作りましょう！」（前向きすぎる決まり文句）
- ダメ：「フフフ、今夜も筆が踊るぜ」（キャラの作りすぎ）

### 評論家の感想（問73）
雑誌の短い評のように、良いところと惜しいところを具体的に短く。評論家ごとに見るところと語尾を変える。

- よい：星野「宇宙の広さはよく出ている。戦いが単調なのが惜しい」
- よい：岩田「曲がいい。それだけで最後まで遊べた」
- よい：松本「序盤が長い。でも、抜けた先は面白いです」
- ダメ：「壮大な宇宙を舞台にした世界観が魅力的です。さらに楽しめると感じました。」（中身がない、整いすぎ）

### ボタンと説明（問74）
ボタンは「押すと何が起きるか」をそのまま書く。説明は言い切りの1文に、数字を添える。

- よい：［募集を出す（¥30万）］［引っ越す］［雇う］［もどる］
- よい：「広報がいると、発売前の期待度が上がる。」「お金が足りない。あと¥80万」
- ダメ：［募集を出しましょう］「広報を雇うと、期待度を上げることができます。」「お金が足りません。」

## 2. 使わない言い方

| 使わない | 代わりに |
|---|---|
| 〜することができます | 〜できる |
| 〜となっております／〜となります | 〜だ・〜です（または言い切る） |
| 〜しましょう！ | 書かない。ボタンの言葉で伝える |
| さまざまな・多彩な・魅力的な・壮大な・圧倒的な | 具体的に何かを書く |
| ワクワク・ドキドキ（気持ちを押し付ける言葉） | 書かない |
| 実現・提供・活用・最適化・向上 | ふつうの言葉にする（「〜を作る」「上がる」） |
| リリース・アップ・ゲット・スキル・ステータス・パラメータ | 発売・上がる・手に入れる・腕前・能力 |
| あなたは〜／あなたの会社 | 主語を書かない。社名で書く |
| 〜的な（印象的な、本格的な） | 具体的に書く |
| 待望の・ついに・いよいよ・堂々の | 書かない（本当に節目のときだけ「ついに」） |
| 絵文字 | 使わない（ひらめきの電球はドット絵で出す） |

## 3. 気をつけること

- 「！」は本当に大きいことだけ。1つの画面に2つ以上出さない
- 体言止め（「〜発売。」「〜達成。」）を続けない
- 同じ形の文を3つ並べない（「〜した。〜した。〜した。」）
- 説明しすぎない。わかることは書かない
- 呼び方は名字だけ（「佐藤」）。社員のひとことでは、社員どうしは「さん」をつける
- 数字はアラビア数字。お金は「¥320万」「¥4.2億」
- 画面の名前・ボタンは、ヒアリングで決めた言葉に合わせる（開発・社員・組織・経営・業界、記録、設定、企画、規模、機種、担当、分かれ道、レビュー、期待度、予約、覚醒）
