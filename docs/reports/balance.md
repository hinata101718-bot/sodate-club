# 数字のバランスの記録

確かめ方：`npx vite-node scripts/balance.ts`（N=シーズン数、SEEDS=クラブのシード）。
3つのクラブ（静岡県・鳥取県・大阪府などから始める）を、「おまかせのオーナー」で遊ばせて数字を見る。
おまかせのオーナー：昇格会議はコーチのおすすめ、契約は自動で更新、お金に余裕があれば施設を強化、スカウトの候補で伸びしろの大きい子を獲る。

目安（企画書・感想 4）
- 1試合の得点：平均2.0〜3.0点
- 力の差が3〜6の試合で、強いほうの勝ち：6〜7割
- 先発の総合力：1部の平均72〜75、2部65〜70、3部50〜60。1部のMVPクラス82〜85
- 大きな覚醒：めったに起きない（全画面の演出が特別に感じられるくらい）
- 昇格までは、ふつうに遊んで2〜4シーズンほど（企画書 17★）
