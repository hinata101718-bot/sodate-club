# ヒアリング記録（人事のゲーム）

書き方：問番号・決まったこと・おすすめどおりか・ヒナタさんの言葉

- 最初の言葉・「人事のゲームを作りたい。採用と組織作りに特化したもの」
- 問1・PRESS START とは別のゲームにする（このリポジトリに新しいアプリとして置き、採用と組織作りだけを深く遊ぶ）・おすすめどおり・「別のゲーム（おすすめ）」
- 問2・いちばん味わいたいのは「組織がかみ合う」（人の相性や役割を考えて部署・チームを組み、うまく回るのを楽しむ）・おすすめ（人を見抜く）とはちがう・「組織がかみ合う」
- 問3・プレイヤーの立場は人事部長（社長から人数と予算の目標が来て、採用と配置を任される）・おすすめどおり・「人事部長（おすすめ）」
- 問4・主にiPhoneのSafariで、縦持ち・指で操作する・おすすめどおり・「iPhoneのSafari（おすすめ）」
- 問5・「かみ合う」と感じたいのは、人と人の相性（合う人どうしだと成果が上がり、合わないともめる）、上司と部下（誰を課長・部長にするかで部下の伸びとやる気が変わる）、能力の穴埋め（足りない力を採用や異動で埋める）。役割のバランスは選ばなかった・おすすめ（相性・役割）の一部＋上司と部下・穴埋め・「人と人の相性（おすすめ）, 上司と部下, 能力の穴埋め」
- 問6・会社はできたばかり（社長と数人だけ。いちから人を集めて組織を作る）・おすすめ（社員30人ほど）とはちがう・「できたばかりの会社」
- 問7・業種はIT・アプリの会社（開発・営業・サポートなど部署が分かれ、組織の形が見えやすい）・おすすめどおり・「IT・アプリの会社（おすすめ）」
- 問8・時間は月ごとに進める（決め終えたら［次の月へ］を押す）・おすすめどおり・「月ごとに進める（おすすめ）」
- 問9・相性は一緒に働くとわかる（最初は「？」。同じ部署で働くうちに「合う」「合わない」が見えてくる）・おすすめどおり・「一緒に働くとわかる（おすすめ）」
- 問10・人を入れる方法は、求人を出して面接（求人にお金をかけるほど応募者が増える）と、春の新卒（秋に内定を出し、春にまとめて入社）。社員の紹介・引き抜きはなし・おすすめどおり・「求人を出して面接（おすすめ）, 春の新卒（おすすめ）」
- 問11・画面の主役は組織図（指でさわって人を動かす。相性は線の色で見える）・おすすめどおり・「組織図（おすすめ）」
- 問12・ゲームに終わりはなく、「社員50人」「上場」などの節目の目標が順に出てくる・おすすめどおり・「終わりなし＋節目（おすすめ）」
- 問13・組織がうまく回ったかは部署ごとの成果でわかる（開発はアプリの出来、営業は契約数など。合わせて会社の売上になる）・おすすめどおり・「部署ごとの成果（おすすめ）」
- 問14・社員の能力は5〜7項目を全員が持つ（項目は次の問で決める）・おすすめ（仕事の腕＋まとめる力）とはちがう・「細かく5～7項目」
- 問15・社員は辞めることがあり、前ぶれがある（やる気が下がると「辞めたそう」と話が来て、面談で引き止められる）・おすすめどおり・「ある。前ぶれがある（おすすめ）」
- 問16・もめごとや困った社員の相談がときどき来て、人事部長としてどうするか選ぶ・おすすめどおり・「ときどき出る（おすすめ）」
- 問17・能力は技術力・営業力・マネジメント力・育成力・企画力・事務力・粘り強さ・地頭の8項目（問14の「5〜7項目」とくいちがうので次の問で確かめる）・おすすめ（技術・話術・発想・まとめる力・育てる力）とはちがう・「技術力、営業力、マネジメント力、育成力、企画力、事務力、粘り強さ、地頭」
- 問18・部署は開発・営業・人事・企画・広報・経理・総務・労務・経営企画・法務の10。サポートは入れない・おすすめ（開発・営業）＋8部署・「開発・営業（おすすめ）, 人事、企画、広報、経理、総務、労務、経営企画、法務」
- 問19・見た目はすっきりした会社風（白地に落ち着いた色。社員は丸いイラストの顔で、組織図が見やすい）・おすすめどおり・「すっきりした会社風（おすすめ）」
- 問20・アプリの名前は、中身が固まってから案を出して選ぶ・おすすめどおり・「あとで案から選ぶ（おすすめ）」
- 問21・能力は問17の8項目にする（全員が持ち、部署ごとに生きる項目が変わる）。問14の「5〜7項目」を「8項目」に改める・おすすめどおり・「8項目にする（おすすめ）」
- 問22・部署は人数に合わせて作る（最初は開発・営業だけ。人が増えると「経理がいなくて困っている」などの声が出て、自分で新しい部署を作る）・おすすめどおり・「人数に合わせて作る（おすすめ）」
- 問23・社長は目標と予算をくれる人（半年ごとに「開発を5人増やしたい」などの要望と採用の予算をくれる。売上が伸びると予算も増える）・おすすめどおり・「目標と予算をくれる人（おすすめ）」
- 問24・1か月にできることは人事部の手の数だけ（面接・面談は月に○回まで。人事部に人を入れると回数が増える。異動は自由）・おすすめどおり・「人事部の手の数だけ（おすすめ）」
- 問25・面接では質問を選んで探る（「前の職場で困ったことは？」などを選ぶと、答えから能力や性格の一部が見える。全部は見えない）・おすすめどおり・「質問を選んで探る（おすすめ）」
- 問26・性格は「まじめ」「マイペース」「世話好き」など8種類ほどのタイプに、人ごとのばらつきを足す（タイプどうしの相性＋個人差）・おすすめどおり・「いくつかのタイプ＋個性（おすすめ）」
- 問27・社員は、働くと伸び（部署の仕事で使う能力が上がる）、上司の育成力で伸び方が変わり、若いほど伸びる（新卒は大化けすることがある）。研修はなし・おすすめ（働く・上司）＋若さ・「働くと伸びる（おすすめ）, 上司の育成力で変わる（おすすめ）, 若いほど伸びる」
- 問28・役職は主任→課長→部長→役員。人事部長が昇進させる人を決め、上げると給料とやる気が上がり、選ばれなかった人は下がることもある・おすすめどおり・「主任→課長→部長→役員（おすすめ）」
- 問29・お金は人事のお金だけ（採用の予算と社員の給料。給料の総額が売上より多いと社長に叱られる）。倒産・借金はなし・おすすめどおり・「人事のお金だけ（おすすめ）」
- 問30・給料を決めるのは採用時と昇進時だけ（内定で給料を示し、安いと断られることがある。そのあとは役職で決まる）・おすすめどおり・「採用時と昇進時だけ（おすすめ）」
- 問31・毎年決まって起きるのは、秋の内定と春の入社式、春の人事異動（年に一度、役職と配置をまとめて決め直す）、年末の評価・ボーナス（一年の成果をふり返り、社長からも評価される）。忘年会・社員旅行はなし・おすすめ（入社式・内定・異動）＋年末の評価・「春の入社式・秋の内定（おすすめ）, 春の人事異動（おすすめ）, 年末の評価・ボーナス」
- 問32・遊ぶのは寝る前に15〜30分（数か月分進めて、いいところでやめられる）・おすすめどおり・「寝る前に15～30分（おすすめ）」
- 問33・組織図では顔を長押しして運ぶ（運んでいるあいだ、置き先の部署に相性と成果の変わり方の目安が出る）・おすすめどおり・「顔を長押しして運ぶ（おすすめ）」
- 問34・月末の結果は月報の画面で見せる（部署ごとの成果、よかった組み合わせ・もめた組み合わせ、入社・退社が1枚にまとまる）・おすすめどおり・「月報の画面（おすすめ）」
- 問35・最初に触る版から、決めたものを全部入れる（新卒・春の異動・年末の評価・もめごとも）・おすすめ（芯だけ先に）とはちがう・「決めたものを全部」
- 問36・作り始める前に、相性の仕組みや部署ごとの成果など、細かいところをもっと聞く・おすすめ（企画書→見本）とはちがう・「もっとヒアリング」
- 問37・相性は同じ部署（課）の人どうしで効く。上司と部下の相性は特に強く効く・おすすめどおり・「同じ部署の人どうし（おすすめ）」
- 問38・相性は少しずつ変わる（一緒に成果を出すと仲が深まり、もめると悪くなる。「元の相性」と「今の仲」がある）・おすすめどおり・「少しずつ変わる（おすすめ）」
- 問39・部署ごとに生きる能力は主＋副の2つ（例：開発＝技術力＋地頭、営業＝営業力＋粘り強さ、経理＝事務力＋地頭）。上司はこれにマネジメント力・育成力が加わる・おすすめどおり・「部署ごとに主＋副（おすすめ）」
- 問40・開発・営業以外の部署の成果は、会社全体へのおかげで表れる（経理＝無駄な支出が減る、労務＝辞める人が減る、広報＝応募者が増える など）。人数が増えるほど、いないと困る・おすすめどおり・「会社全体へのおかげ（おすすめ）」
- 問41・求人は広告の大きさだけを決める（お金をかけるほど応募者が増える。どんな人が来るかは運）・おすすめ（部署と条件を決める）とはちがう・「広告の大きさだけ」
- 問42・面接は一次と最終の2回（一次で絞り、最終には配属先の上司も同席して相性のヒントが出る）・おすすめ（1回で質問3つ）とはちがう・「一次と最終」
- 問43・内定を出しても断られることがある（給料が望みより安い、他社にも受かっている など。力のある人ほど取り合いになる）・おすすめどおり・「ある（おすすめ）」
- 問44・社員には希望がある（「いつか企画をやりたい」など。叶うとやる気が上がる。面接や面談でわかる）・おすすめどおり・「ある（おすすめ）」
