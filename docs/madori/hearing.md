# ヒアリング記録（間取り・家の見た目アプリ）

書き方：問番号・決まったこと・おすすめどおりか・ヒナタさんの言葉

- 問1・間取りと家の見た目（外観）を同じくらい大事にする。間取りを描くと、その形のまま外観が立体で見え、外壁や屋根の色も選べる・おすすめどおり・「両方同じくらい（おすすめ）」
- 問2・主にiPhoneのSafariで、縦持ち・指で操作する・おすすめどおり・「iPhoneのSafari（おすすめ）」
- 問3・本当に家を建てる予定があり、ハウスメーカーや工務店との相談に使えるくらい、広さ（帖・坪）や寸法を正確にする・おすすめ（夢を描いて楽しむ）とはちがう・「本当に家を建てる予定」
- 問4・外観は3Dの家を指で回したり近づいたりして見る・おすすめどおり・「立体で回して見る（おすすめ）」
- 問5・マス目は910mm（半間）単位。1マス＝91cm、2マス×2マス＝2帖・おすすめどおり・「910mm（半間）単位（おすすめ）」
- 問6・平屋と2階建てを作れる。1階・2階を切りかえて描く・おすすめどおり・「平屋と2階建て（おすすめ）」
- 問7・土地の広さ・方角（北の向き）・道路の位置を入れ、その中に家を置く・おすすめどおり・「土地の広さと向きを入れる（おすすめ）」
- 問8・部屋は種類を選んでマス目を指でなぞって四角を描き、あとから角を引っぱって大きさを変える・おすすめどおり・「指でなぞって四角を描く（おすすめ）」
- 問9・置けるものはドア・窓、階段・収納、キッチン・お風呂などの設備。家具は置かない・おすすめ（ドア・窓、階段・収納、家具）から家具をはずし、設備を足す・「ドア・窓（おすすめ）, 階段・収納（おすすめ）, キッチン・お風呂などの設備」
- 問10・外観では屋根の形、外壁・屋根の色、外壁の素材、外構を選べる・おすすめ（屋根の形、色）＋素材・外構・「屋根の形（おすすめ）, 外壁・屋根の色（おすすめ）, 外壁の素材, 外構」
- 問11・数字は広さだけ（部屋ごとの帖数、階ごと・全体の床面積〔㎡・坪〕、建ぺい率・容積率の目安）・おすすめどおり・「広さだけ（おすすめ）」
- 問12・いくつもの案を保存・コピーして比べられ、間取り図と外観を画像で保存・共有できる・おすすめどおり・「いくつもの案を保存して比べる（おすすめ）, 画像で保存・共有（おすすめ）」
- 問13・画面は家事アプリのような和紙の色合いで、間取り図は住宅チラシのように部屋ごとに淡い色分け・おすすめどおり・「やさしい紙と木の色（おすすめ）」
- 問14・間取り図と3Dの外観（と土地）はタブで切りかえ、それぞれ画面いっぱいに使う・おすすめどおり・「タブで切りかえ（おすすめ）」
- 問15・はじめは見本の間取り（「2階建て 3LDK」「平屋 2LDK」など）を元にするか、白紙から始めるか選べる・おすすめどおり・「見本の間取りから選べる（おすすめ）」
- 問16・アプリの名前は「ゆめのおうち」・おすすめ（わが家の間取り帳）とはちがう・「ゆめのおうち」
- 問17・ドア・窓は「ドア・窓」を選んで壁をタップし、種類（開き戸・引き戸・腰窓・掃き出し窓など）と幅を選ぶ・おすすめどおり・「壁をタップして種類を選ぶ（おすすめ）」
- 問18・3Dでは屋根や2階を外して、ドールハウスのように中をのぞける・おすすめどおり・「屋根や2階を外してのぞける（おすすめ）」
- 問19・外構は駐車場、ウッドデッキ・テラス、庭・木・花壇、フェンス・門・アプローチ・おすすめ（駐車場・デッキ・庭）＋フェンス・門・アプローチ・「駐車場（おすすめ）, ウッドデッキ・テラス（おすすめ）, 庭・木・花壇（おすすめ）, フェンス・門・アプローチ」
- 問20・外壁は家全体で基本の素材・色を一つ選び、一部（2階だけ・この壁だけなど）をアクセントの素材にできる・おすすめどおり・「家全体で一つ＋アクセント（おすすめ）」
- 問21・3Dで季節と時刻をつまみで動かすと、土地の向きに合わせて太陽の向きと影が変わり、日当たりがわかる・おすすめどおり・「季節と時刻を動かして見る（おすすめ）」
- 問22・操作の助けは、もとに戻す・やり直す、2本指で拡大・移動、初めてのときの使い方の案内・おすすめ（戻す・2本指）＋案内・「もとに戻す・やり直す（おすすめ）, 2本指で拡大・移動（おすすめ）, 使い方の案内」
- 問23・最初の版から、今回決めたことをすべて入れてから触る・おすすめ（間取り＋3D外観を先に）とはちがう・「ぜんぶ入れてから」
