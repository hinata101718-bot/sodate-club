# 企画書（仮題：「育ての街クラブ」★）

もとになる記録：docs/new/hearing.md（問1〜問53）

★がついているところは、Claudeが決めたところです。ちがっていたら教えてください。直します。
★がついていないところは、ヒアリングでヒナタさんが決めたところです。

---

## 1. ひとことで言うと

本物の日本の、自分で選んだ県に、できたばかりのサッカークラブを作る。
オーナーとして監督・コーチ・スカウトを雇い、ユースや練習生から拾った無名の若手が、数年かけて「化ける」のを見守るゲーム。

- ジャンル：クラブ経営シミュレーション（問1）
- 遊びの芯：選手を育てる（問3）
- いちばん味わいたい瞬間：無名の若手が数年かけて化ける（問4）
- 手本：サカつく中期作（04〜06ごろ）を中心に、カルチョビットを少し（問5）。名前や決まった仕組みはまねせず、すべてオリジナルにする
- 前からあるサカつく風のゲームとの重なりは気にせず、ゼロから作る（問2）

## 2. 遊ぶ場面

- 移動中：1回5〜10分、片手で縦に持って遊ぶ（問6）
- 寝る前：1回15〜30分、落ち着いて遊ぶ（問6）
- iPhoneのSafariで遊ぶ。GitHub Pagesで公開する
- 移動中は「まとめて進むボタン」で一気に、寝る前は1週ずつ見どころを見ながら、と遊び分けられる（問43）

## 3. 世界と始まり

- 舞台：本物の日本。国・県・市の名前は本物。クラブ・リーグ・選手・監督などの名前はすべてオリジナル（問8）
- ホーム：47都道府県から1つ選ぶ。県ごとに代表の市を1つ用意する（問10）
  - 町の大きさは決めず、選んだ県によって人口・お金の集まりやすさ・ユースに入る子の数が変わる（問9・問50）
  - 代表の市は、各県の県庁所在地にする★
  - 代表の市に本物のクラブがあってもかまわない。架空のクラブがそこにできる、という形にする（問8の説明）
- 始まり：できたばかりの新しいクラブ。名前・色・エンブレムを自分で決め、3部から始める（問11）
  - エンブレムは、形（盾・丸など数種類）と色の組み合わせで作る★
  - 最初の選手は、地元の若手中心の22人ほどで、能力は低め★

## 4. プレイヤーの立場

- オーナー。お金・施設・人を雇うこと・選手の獲得と売却を決める。試合は見守る（問7）
- 監督には、次の2つだけ伝えられる（問32）
  - 若手の使い方の方針（「若手を多めに」「今は勝つことを優先」など）
  - 「この選手を使ってほしい」という頼み（聞くかどうかは監督次第）
- 試合の作戦・選手交代・練習メニューは、オーナーは決めない（問7・問32・問17の追記）

## 5. リーグと大会

- 3段（1部・2部・3部）×各12クラブ、全36クラブ（問12・問13）
- ホームとアウェイで1回ずつ戦い、年22試合（問13）
- 上位2つが昇格、下位2つが降格（問14）
- 全36クラブが出る勝ち抜きの大会が年1つ（問44）
  - 1回戦は3部のクラブから始まり、勝ち進むと上の段のクラブが出てくる形にする★
  - 試合数は、リーグの22試合に1〜5試合ほど足される
- 勝ち点：勝ち3・引き分け1・負け0。並んだら得失点差で決める★
- 他の35クラブは、自分の県以外の46県のうち35県に1つずつ置く（自分のクラブとあわせて36県）。どの県に置くかはゲームを始めるときに決まる★

## 6. 1年の流れ

時間は1週ずつ進む。「次に決めることまで進む」ボタンで、まとめて進むこともできる（問43）

| 時期 | 出来事 |
|---|---|
| 1月 | オフの休み（ケガと疲れが回復）（問45） |
| 2月はじめ | ユースの春の昇格会議（トップに上げる子を決める）（問27） |
| 2月なかば〜下旬 | 春のキャンプ（選手が伸びやすい特別な期間）。昇格会議で上げた子も連れて行ける（問45・企画書への意見） |
| 3月 | シーズン開幕★ |
| 3月〜11月 | リーグ戦22試合と勝ち抜きの大会。毎月1回、ユースの報告会議（問27） |
| 7月〜8月 | 夏の移籍の期間（選手の売り買いができる）（問45） |
| 12月 | 年末の表彰（リーグで一番の選手、一番の若手など）（問45）／契約更新の時期（問45）／冬の移籍の期間（問45） |

- 順番は「昇格会議 → キャンプ → 開幕」（企画書への意見）
- 月日の割り当ては★
- 年末の表彰は、目標（問16）にはせず、記録として見せる★

## 7. ゲームの終わりと目標

- 終わりはなく、ずっと続けられる（問15）
- 節目の目標は、成績の目標だけ（問16）
  - 例：3部で昇格、2部で昇格、1部で優勝、勝ち抜きの大会で優勝★（目標の並びと中身は★）
  - 1つ達成すると、次の目標が出てくる

## 8. 選手

### 8-1. 人数

- トップチームは22〜25人（問42）。ユースは別に数える
- ユースは、1学年4〜6人×3学年で、12〜18人ほど★

### 8-2. 能力（8項目、1〜99の数字＋色）

- フィールドの選手：スピード・シュート・パス・ドリブル・フィジカル・ディフェンス・スタミナ・IQ（問21）
- ゴールキーパー：セービング・飛び出し・キック・ハイボール・スピード・フィジカル・スタミナ・IQ（問22・問23）
- 1〜99の数字で見せ、強さに応じて色を変える（問20。上限は99で、100は存在しない：企画書への意見）
  - 色の境目：〜69 灰色、70〜79 銅、80〜89 銀、90〜99 金（企画書への意見）
- 強さの目安（試作への感想 4）
  - 1部のMVPクラス：82〜85
  - 1部の先発の平均：72〜75
  - 2部の先発：65〜70
  - 3部の先発：50〜60
  - ポテンシャル（どこまで伸びるか）の上限は88★
- 画面では2列×4行に並べる（問21の説明）
  - キーパーは上の段に「キーパーの技」、下の段に「体と頭」を並べる★

### 8-3. ポジション

ポジションは8つ（企画書への意見）

| 場所 | ポジション | ★ひとこと説明 |
|---|---|---|
| ゴール | GK | ゴールキーパー |
| 守り | CB | 守りの真ん中 |
| 守り | SB | 守りの横（サイド） |
| 中盤 | DM | 中盤の後ろ寄り。守りの盾 |
| 中盤 | CM | 中盤の真ん中。攻めと守りのつなぎ役 |
| 中盤 | AM | 中盤の前寄り。攻めの組み立て役 |
| 攻め | WG | 攻めの横（サイド） |
| 攻め | ST | 攻めの真ん中。点取り屋 |

- 左右は分けない（SB・WGは、左でも右でも同じポジションとして扱う）★
- ポジションの適性は、8つのポジションそれぞれに ◎・○・△・× の4段階でつく。選手によって変わる（企画書への意見）
  - ◎ の数は、平均1〜2つ。多い選手で4つ（企画書への意見）
  - 試合で出せる力：◎ はそのまま、○ は少し下がる、△ はかなり下がる、× は大きく下がる★（どれくらい下がるかは試作で決める★）
  - 適性は、そのポジションで試合に使っていると伸びる（例：△ → ○ → ◎）（企画書への意見）
    - 1段上がるまでの目安は、そのポジションで半シーズン〜1シーズンほど出場すること★
    - 適性が上がったことは、週の報告で光らせて見せる（問25と同じ見せ方）★
- 画面では、ポジションの略語に、場所ごとの色（ゴール・守り・中盤・攻め）をつけて見分けやすくする★

### 8-4. 年齢と隠れた素質

- 伸びる時期（成長期）は選手ごとにバラバラ。「早い・ふつう・遅い」の3つの型には分けない（問24・企画書への意見）
  - 多くの選手の成長期は、16〜28歳くらいの間のどこかにある（企画書への意見）
  - 成長期の長さも選手ごとにちがい、短い子は2〜3年、長い子は6〜8年ほど★
  - ごくまれに、16歳より前から伸びている子や、28歳を過ぎてから伸びる子もいる★
  - 成長期を過ぎると伸びはゆるやかになり、30歳前後から少しずつ下がり始める（下がり始める年も選手ごとにちがう）★
- 「どこまで伸びるか」と「伸びる時期」は隠れている（問17）
- 「どこまで伸びるか」（ポテンシャル）は、シーズンでの活躍で多少上下する（企画書への意見）
  - シーズンで大きく活躍すると少し上がり、ほとんど活躍できないと少し下がる★
  - 1シーズンで動くのは、上がるときで最大5ほど、下がるときで最大3ほど★
  - 動いたかどうかは数字では見せず、年末にコーチのひとことで伝わる（例：「今年の活躍で、あいつはひと皮むけた」）★
- 素質は、スカウトやコーチのひとことの評価で、ぼんやりわかる。腕のいい人ほど当たる（問18）
  - 例：「化けるかもしれない」「まだ伸びる時期が来ていない」「もう伸びしろは少ない」★
- 引退：引退する年に下限は設けない（企画書への意見）
  - 能力が下がってきた選手や、試合に出られなくなった選手から引退を考え始める★
  - 何歳で引退するかは選手ごとにちがい、20代で引退する選手もいる★
  - 引退はシーズンの終わり（12月）に知らされる★

### 8-5. 伸び方

選手は次のもので伸びる（問17と、その追記）

- 試合に出ること：出るほど経験がたまり、伸びやすくなる
- 年齢と素質：伸びる時期と、どこまで伸びるかの上限
- 出来事：急に伸びる、ケガ、いいコーチとの出会いなど
- コーチが自動で組む練習：オーナーは中身を決めない。毎週少しずつ伸びる
- 練習場：強化すると、練習での伸びがはっきり大きくなる（問39と問17の追記）
- コーチの腕前：受け持つ項目の伸びやすさが変わる（問34）
- 監督の育てる腕前：試合に出た選手の伸びやすさが変わる（問33）
- 春のキャンプ：その期間は伸びやすい（問45）

### 8-6. 調子と疲れ

- 調子の波（好調・不調）がある。週ごとに変わり、試合での力に少し影響する（問52）
- 疲れがある。連戦で力が落ち、ケガをしやすくなる。オフの休みで回復する（問52・問45）

### 8-7. 「化けた」ことの見せ方

- ふだんは、週の報告で、大きく伸びた項目だけ色が変わって光る（問25）
- 大きな覚醒が起きたときだけ、全画面の演出を出す。大きな金色の「覚醒！！」の見出しと、数字が大きく跳ね上がるようすを出す。選手の台詞は出さない（問25・感想 6・7）
  - 「大きな覚醒」は、1つの項目が1度に10以上、または合計で20以上伸びたとき★
  - 全画面のあいだは短い効果音を鳴らす（音がオンのとき）（問49）
- 新しい特殊能力が身についたときや、悪い特殊能力を克服したときも、週の報告で光らせる（8-8）★
- 週の報告で光らせるのは、+2以上伸びた項目（試作で決めた）★。「伸びた能力が光るのは良い」（感想 5）

### 8-8. 特殊能力（問65〜問79）

選手の個性を出すしくみ。「持ち味」と「プレーの好み」を1つにまとめたもの（問65）。名前は「特殊能力」（企画書への意見）。中の1つ1つの名前はオリジナルにする。

- 1人が持てる良い特殊能力は0〜5つ。無名の子は0〜1つ、育つと増え、スター選手は4〜5つ（問69）
- 悪い特殊能力は別に数える。1人0〜2つほど★
- 効き目は種類ごとにちがう。めったに起きない場面ほど強め、毎試合効くものは小さめ。平均は「その場面だけ能力が+5〜8ほど上がる」くらい（問70）。数字は試作で決める★
- どの特殊能力も、見どころの文に出る（例：「得意のロングシュートが突き刺さる！」）

## 13. 試合

### 13-1. 見方

- 見どころの場面だけを短く見るのがメイン。文字の実況で試合の流れを追うこともできる（問35）

- 見どころに選ぶ場面（問63）
  - ゴールの場面は必ず全部入れ、残りは惜しい場面（メイン）
  - 流れが変わった場面（同点・逆転・並び方の切りかえの直後）
  - 記念の場面（初出場・初ゴール・ユース出身の初ゴールなど）
  - 守りの見せ場（GKのビッグセーブ、体を張った守りなど）
- 試作で決まった見せ方（感想 1〜3・8〜18）
  - 1つの場面は「展開 → 勝負 → シュート → 結果」の行に分け、画面のどこを押しても1文ずつ進む。見どころも実況も同じ
  - 結果（ゴールの札・点数）は、最後の行が出てから出す
  - 場面の種類の札（「クロス」など）、見どころに選んだ理由の札（「守りの見せ場」など）、くらべた能力の数字は出さない
  - 特殊能力が働いた行は、金色の札「特殊能力「名前」 選手名」で出し、さらにカットイン（「特殊能力発動！」）を出す。GKの特殊能力が働いて入らなかったときは、必ずGKが止めた文にする
  - ゴールが決まった瞬間は、クラブの色の帯が飛び込む「ゴール！！」のカットイン（得点者・時間・点数）
  - 新しい文が出たら、画面は自動で下まで送る
  - 「最後まで出す」で一気に出せる（そのときはカットインを出さない）
  - 実況は、見どころ以外に、キックオフ・試合の流れ・ファウル・前半終了・後半開始・交代・試合終了も書く

### 13-2. 勝ち負けの決まり方

問54〜問63で決めた形です。数字の細かいところは試作で決めます。

**全体の考え方**
- 強いほうがよく勝つ。力の差がはっきりあれば6〜7割くらい勝つ。番狂わせもときどき起きる（問54）
- 「チームの強さ」で結果を先に決めるのではなく、場面ごとの1対1の勝ち負けを積み上げて、結果ができあがる（問57）

**流れ**
1. 試合の前に、監督が並び方を選ぶ（問55・問56）
2. 試合の中で、決定機の場面が両チームに来る（問58）
   - どちらに何回来るかは、中盤（DM・CM・AM）の強さで基本の回数が決まり、並び方と監督の戦い方で増えたり減ったりする
   - 1試合の決定機は、両チームあわせて8〜12回ほど★
   - 試合を15分ずつの6つの時間に分けて、時間ごとに決定機が起きるかを決める★
3. 決定機ごとに、関わる選手どうしの能力が1対1でぶつかる（問57）
4. 点差に応じて、監督が並び方を変えたり、選手を代えたりする（問56・問62）

**決定機の場面（全部で11種類。アップデートのたびに増やしていく）（問59）**
