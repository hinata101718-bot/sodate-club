# PC版の決めごと（「頂点への道」とのいいとこどり）

もとになる話し合い：2026-11-13 のヒアリング（下の表）。ここに書いていないことは、もとの企画書（docs/new/kikaku.md）のとおり。

## ねらい

- 画面・移籍・データの見やすさは「頂点への道」（PC向けのダッシュボード）を手本にする
- 試合と能力は、このリポジトリの「育ての街クラブ」のしくみをそのまま使う
- PC専用。スマホ版の画面（src/ui の大部分）は外した。前のスマホ版のセーブは引き継がない

## ヒアリングで決めたこと

| 問い | 決めたこと |
|---|---|
| どこを土台にするか | このリポジトリ（TypeScript・テストつき）。画面だけPC向けに作り直す |
| プレイヤーの立場 | GM兼監督（並び方・戦い方・先発・練習を自分で決める） |
| 雇う「監督」 | ヘッドコーチにする。育てる腕（試合に出た選手の伸び）と、試合中の交代・先発を任せたときの選手選びに効く |
| 練習 | テーマ・強さ・個別メニューを自分で決める。コーチの腕は、受け持つ能力の伸びに効く |
| 残すしくみ | 人を雇う・ユースの学年と会議・月ごとの1年の流れ・選手の気持ちと会議 |
| オーナーへの頼み・月の会議 | 「頼み」はなくす（自分で采配するため）。選手の気持ちと月・年の会議は残す |
| 頂点への道から入れるもの | 実績とミッション・難易度と解任・スポンサー選びとチケットの値段・ランダムな出来事と殿堂 |
| 戦術 | 並び方7つ・戦い方5つ（育ての街）＋攻めと守りの方針（攻撃的・バランス・守備的）＋キッカー（CK・FK・PK） |
| 潜在の見せ方 | ★（幅あり）とコーチのひとこと。腕のいいコーチ・スカウト部のレベルで幅がせまくなる |
| 年の目標 | オーナーが3つ出し、GMが選ぶ。届かないと信頼が下がり、0で解任（イージーは解任なし） |
| 試合の見せ方 | 頂点への道のピッチとスコアボードに、育ての街の実況・解説を流す。試合のあとは流れのグラフ・シュートの位置・1対1・交代・評価点 |
| 試合のエンジン | FM型に作りかえた：22人とボールを本当に動かし、結果はその中から生まれる。ほかのクラブどうしの試合も全部同じエンジン。試合の途中で一時停止して、並び方・戦い方・方針・交代を変えられる（すぐに効く）。実況は試合の動きから作る（2026-11-13 のヒアリング） |
| 移籍 | 混ぜる：交渉（移籍金→給料・年数、3往復）とオファー（値上げ）・売りに出す・契約を切る。ほかのクラブの選手は全員見られるが、スカウトが調べるまで総合力のおおよそ（「60台」）しかわからない |
| 施設 | 両方を合わせる：スタジアム・練習場・ユース・寮・メディカル・スカウト部・グッズショップ（どれもレベル5まで） |
| 公開 | ブランチとPR。main に入ると GitHub Pages に出る |

## しくみのメモ（Claudeが決めた数字。遊んでみて変える）

- 難易度：はじめのお金 ×1.6（イージー）／×1／×0.6（ハード）／×0.35（レジェンド）。選手の強さ +3／0／−2／−4。スポンサーの額 ×1.15／×1／×0.92／×0.85
- 攻めと守りの方針：攻撃的はラインが上がりサイドバックが前に出て、リスクのあるパスとシュートが増える（点を取りやすく、取られやすい）。守備的はラインが下がり、ディフェンス・IQが上がる（点が入りにくい試合になる）
- 練習の強さ：軽め（伸び×0.78・疲れが抜けやすい）／ふつう／ハード（伸び×1.3・疲れが抜けにくい・練習でケガをすることがある）。休養のテーマは伸びが小さく、疲れが大きく抜ける
- 個別練習：重点にした能力は約2.5倍、ほかは0.8倍
- スポンサー：安定型（決まった額）・成果型（勝つたびにボーナス）・攻撃型（点を取るたびにボーナス）を、毎年1月に選ぶ
- チケット：段の相場（3部 1,800円・2部 2,300円・1部 3,000円）を1として、値段を上げると1人あたりが増え、お客さんが減る。相場の1.5倍をこえると人気が少し下がる
- 実績は54。報酬は銅300万円・銀1,200万円・金5,000万円
- 殿堂：このクラブで150試合・50点・表彰2回（ユース出身は100試合）のどれかを満たした選手がクラブを去ると入る
- オーナーの信頼：はじめは60。年の目標の結果で上下し、お金が足りない月も下がる

## ファイル

- src/core/gm.ts：PC版で足したしくみ（難易度・戦術と練習の状態・スポンサー・ミッション・実績・出来事・殿堂・解任）
- src/pc/：PC版の画面（app・views・views2・modals・matchplay・newgame・style.css）
- scripts/pcsim.ts：おまかせのGMで何シーズンか進めるテスト（`N=6 DIFF=hard npx vite-node scripts/pcsim.ts`）
- tests/gm.test.ts：PC版のしくみのテスト
- src/core/sim.ts：試合のエンジン（FM型）。src/core/movement.ts・src/core/data/posmodel.json・src/core/data/ballmodel.json・scripts/learn_positions.py・scripts/learn_ball.py：実データ（SkillCorner・StatsBomb）から学んだ立ち位置とボール回し（docs/pc/movement.md）
- scripts/simbench.ts・scripts/matchcal.ts：エンジンの数字と速さを本物と比べる
