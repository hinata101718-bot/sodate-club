# 試合の2Dの動き（実データから学んだ立ち位置）

## 出典
Metrica Sports のサンプルデータ（Sample Game 1・2）を使った。https://github.com/metrica-sports/sample-data
- データは匿名化された実際の試合の、選手とボールの位置（1秒に25回）とイベント（パスなど）
- 公開するときは出典を書く、という決まりなので、ゲームの試合画面とこの資料に出典を書いている
- 生のデータ（約120MB）はリポジトリに入れていない。入れているのは、集計した数字（`src/pc/movemodel.json`・約20KB）だけ

## 学んだもの
`scripts/learn_movement.py` で集計した。
- 選手ごとに、その試合でのふだんの位置（平均の位置）を出し、ピッチを縦5×横3のエリアに分けて、どのエリアの選手かを決める
- ボールの位置（7×5のマス）と、自分のチームがボールを持っているかごとに、その選手がふだんの位置から何mずれるか（平均とばらつき）を集計する
- 向きは、自分のチームが右へ攻める向きにそろえる（後半やアウェーは反転）
- キーパーは別に扱う（ゴールの前で、ボールの横の位置に少しだけ合わせる）
- 同じチームのパスの間隔（中央値 約2.7秒）も出した

例：ボールが自陣の深いところにあって守っているとき、センターバックはふだんの位置から約20m下がり、ボール側へ約8m寄る。

## ゲームでの使い方（src/pc/movement.ts・src/pc/matchplay.ts）
- 各選手の行き先＝並び方の基本の位置＋学んだずれ（ボールの位置・どちらが持っているか）＋ゆっくり変わる小さな揺らぎ
- 選手は毎フレーム、ばねのようになめらかに行き先へ向かう（急に向きを変えない・速さに上限がある）
- データのない組み合わせは、いちばん近いエリアの値で補う。となりのボールのマスともならして、カクッと動かないようにする
- 場面と場面の間は、ボールを持っている側が近くの味方へ前向きにパスをつなぐ（ときどき相手が奪う）。流れのグラフで押している側が、ボールを持ちやすい
- 実況の行に出てくる選手にボールが渡る。2人目が味方ならパスの受け手、相手なら寄せてくる。シュート・セーブ・枠の外・ゴールは、行の言葉から決める
