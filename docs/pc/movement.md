# 試合のエンジン（FM型）と、実データから学んだ動き

## しくみ（`src/core/sim.ts`）
試合は、22人とボールを試合の時間で少しずつ動かして進める。点もシュートもパスの数も、この動きの中から生まれる。自分の試合も、ほかのクラブどうしの試合も、全部このエンジンで動かす。

- **選手の立ち位置**：役割のふだんの位置＋学んだずれ（ボールの位置・ボールを持っているか）＋戦術
  - 戦い方：守りのラインの高さ・幅・プレスをかける場所と人数・ゴールキックのつなぎ方・パスの好み（短い／長い／横／前）
  - 方針：攻撃的はラインが上がりサイドバックが前に出る（そのぶん守りが手薄）。守備的はラインが下がり守りの力が上がる
  - 守るときは近くの相手のゴール側に立つ（マーク）。ボールに一番近い選手が寄せてボールを奪いにいく
  - 攻めるときはオフサイドラインの手前で待ち、FW・WG・AM（2列目からの飛び出しのCM）が裏へ走る
- **ボールを持った選手の判断**：実データの行き先から候補を出し、そのほか裏へのパス・クロス・ドリブル・シュート・クリアをくらべて、一番よさそうなものを選ぶ（IQが高いほど上手に選ぶ）
  - くらべ方：その場所でボールを持つ値打ち（点につながりやすさ）× うまくいく確率 − 失ったときの危なさ
  - パスが通る確率：実データの成功率を土台に、パス・IQ・距離・受け手のまわりの相手・パスの線上の相手・プレッシャー
  - ドリブル：前にいる相手と1対1（ドリブル・スピード・フィジカル 対 ディフェンス・フィジカル・スピード）
  - シュートの入りやすさ：ゴールの見える角度と距離（xG）× シュート力とキーパーの差 × 前にいる相手の数。ブロック・枠内・ポスト・セーブ・こぼれ球
- **反則とカード**：タックル・競り合い・抜かれたときにファウル。ペナルティエリアの中ならPK
- **セットプレー**：スローイン・ゴールキック・コーナー・フリーキック（直接ねらう／ゴール前へ入れる）・PK・キックオフ。ボールが止まっている時間もある（実際の試合と同じく、ボールが動いているのは90分のうち6割ほど）
- **疲れ**：走った量とスタミナで体力が減り、能力とスピードが下がる。エンジン・スタミナ切れも効く
- **特殊能力**：その場面（抜け出し・ドリブル突破・クロス・セットプレー・ミドルシュート・こぼれ球・カウンター・守りのミスなど）の能力に上のせ。働いたら実況に札で出る
- **交代**：ヘッドコーチ（相手は監督）が、疲れ・点差・イエローで交代する。PC版では自分で交代もできる
- **実況**：起きたプレーから作る。言い回しは `phrases.ts`・`commentary.ts`

### 本物との比べ（`scripts/matchcal.ts`・`scripts/simbench.ts`、同じ段どうし）
| | エンジン | 本物の目安 |
|---|---|---|
| 1試合の点 | 約2.6 | 約2.6 |
| 1チームのパス（成功率） | 約490（80%） | 約450（80%） |
| 1チームのシュート（枠内） | 約12（38%） | 約12（35%） |
| ファウル・イエロー（1チーム） | 約12.7・1.6 | 約12・1.5 |
| オフサイド・コーナー（1チーム） | 約2.2・4 | 約2・5 |
| PK・退場（1試合） | 約0.2・0.1 | 約0.25・0.1 |
| 力の差が3以上で強いほうが勝つ | 約65〜70% | — |

戦い方と方針の強さは、同じ選手どうしで比べて、どれも勝ちが3〜4割ほどになるようにしてある（どれか1つが強すぎないように）。

### 速さ
1試合は、見ないで進めるとき約45ms（ブラウザ）。出来事（判断・ボールが着く・再開）のちょうどの時刻にだけ止まって進めるので、刻みの大きさで結果は変わらない。

## 出典
- 選手の立ち位置：**SkillCorner** の公開データ（A-League 2024/25 の実際の20試合の位置データ。1秒に10回）https://github.com/SkillCorner/opendata
  - 使うときは SkillCorner の名前を出してほしい、という決まりなので、試合画面とこの資料に書いている
- ボールの動き：**StatsBomb** の公開データ（男子の300試合のイベントデータ）https://github.com/statsbomb/open-data
  - StatsBomb のデータであることを出すこと、という決まりなので、試合画面とこの資料に書いている
- 生のデータ（合わせて2GBほど）はリポジトリに入れていない。集計した数字だけを入れている（`src/core/data/posmodel.json` 約60KB・`src/core/data/ballmodel.json` 約50KB）

## 学んだもの
### 選手の立ち位置（`scripts/learn_positions.py`）
- 試合のはじめの役割（GK・CB左右・SB左右・DM左右・AM・WG左右・ST左右など）ごとに集計する（途中から出た選手はのぞく）
- その試合での、その選手のふだんの位置（平均の位置）と、ボールの位置（12×8のマス）と、自分のチームがボールを持っているかごとに、ふだんの位置から何mずれるか（平均とばらつき）
- 役割ごとのふだんの位置（20試合の平均）と、走る速さ（50%・90%・99%の値）
- 向きは、自分のチームが右へ攻める向きにそろえる（後半やアウェーは反転）。y は画面と同じで下が＋（右サイド＝下）

### ボールの動き（`scripts/learn_ball.py`）
- ボールのある場所（12×8のマス。ボールを持つチームが右へ攻める向き）ごとに：パスとドリブルの割合、パスの行き先のマスの割合、パスの成功率、外に出る割合、パスの速さ、次のプレーまでの時間
- コーナー・フリーキック・スローインなどのセットプレーのパスはのぞく

## 試合の画面（`src/pc/matchplay.ts`）
- エンジンをその場で動かし、選手とボールの本当の位置を描く。時計は試合の時間。「ふつう」は本当の90分、2倍・4倍・6倍・10倍
- 実況は、エンジンで起きたプレーのその時刻に出る
- 「見どころだけ」：エンジンを先に進め、ゴール・大きなチャンス・退場が起きたら、その少し前から見せる（位置の記録を巻きもどす）
- 作戦ボード：一時停止・並び方・戦い方・方針・交代（次にボールが止まったときに入る）・ヘッドコーチに交代を任せる
